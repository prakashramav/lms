# Career Intelligence & Placement Ecosystem

## 1. Overview
The Career Intelligence system connects learning milestones to professional employment opportunities through five integrated engines:

```
LEARNING & SKILLS
       │
       ▼
 CAREER ROADMAP & SKILL GAP ANALYSIS
       │
       ▼
  RESUME & PORTFOLIO BUILDER
       │
       ▼
   JOB MATCHING & APPLICATIONS
       │
       ▼
 AI MOCK INTERVIEW PREPARATION
```

---

## 2. Core Modules
1. **Career Paths & Skill Gap**: Maps roles (e.g., Full Stack Engineer, Frontend Specialist) to required skills, evaluating student mastery percentages.
2. **Resume Builder**: Live structured resume editor with AI ATS keyword scoring, section completeness checks, and PDF export.
3. **Public Portfolio**: Unique username portfolio showcase (`/portfolio/[username]`) with project showcases, GitHub links, and privacy controls.
4. **Job Board & Application Tracker**: Direct search, remote/salary filters, application timeline history, and status progression.
5. **AI Mock Interviewer**: Interactive voice/text simulated interview sessions with question-by-question scoring and comprehensive feedback reports.
